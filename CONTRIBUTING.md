
# Contributing to SmallBiz IQ

Thank you for your interest in contributing to SmallBiz IQ!

We welcome developers who want to improve the project, report bugs, suggest features, or improve documentation.

## How to Contribute

1. Fork the repository.
2. Clone your fork locally.
3. Create a new feature branch.
4. Implement your changes.
5. Test your changes.
6. Commit your work with a meaningful commit message.
7. Push your branch.
8. Open a Pull Request.

## Branch Naming

Use descriptive branch names:

- feature/product-management
- feature/sales-analytics
- fix/revenue-calculation
- docs/update-readme

## Commit Messages

Use clear commit messages:

- feat: add product management
- fix: correct sales calculation
- docs: update project documentation
- test: add sales service tests
- refactor: improve application structure

## Contribution Principles

- Write clean and understandable code.
- Follow existing project conventions.
- Include tests when appropriate.
- Update documentation when necessary.
- Do not commit passwords, API keys, or other secrets.
- Explain the purpose of your changes in your Pull Request.

## Questions and Suggestions

Use GitHub Issues to report bugs or propose new features.

Thank you for helping improve SmallBiz IQ!
