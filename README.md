
# SmallBiz IQ

**A Business Analytics and Decision Support Platform for Small Businesses.**

SmallBiz IQ is an open-source web application designed to help small businesses manage their operations, analyse business performance, understand customer demand, and make data-driven decisions.

## Project Vision

Our goal is to provide a centralised platform that supports different types of small businesses, including product-based and service-based businesses.

## Planned Features

- User registration and business management
- Product and service management
- Sales and appointment tracking
- Inventory management
- Business analytics and reporting
- Performance dashboards
- Data-driven recommendations

## Technology Stack

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- HTML, CSS and JavaScript
- Chart.js

## Getting Started

### Prerequisites

- .NET 10 SDK
- Git
- Visual Studio Code (or another compatible IDE)

### Run the application

```bash
git clone https://github.com/Nathanaelle25/SmallBizIQ.git
cd SmallBizIQ
dotnet run --project src/SmallBizIQ.Web
```

Open the local address displayed in your terminal.
